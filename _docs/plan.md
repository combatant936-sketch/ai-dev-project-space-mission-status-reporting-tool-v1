
# Space Mission Status Reporting Tool — Requirements

## 1. Authentication and Roles
- Email and password login.
- Admin and Team Member roles.
- Role-based access control.

## 2. Mission Management
- Admin can create, view, edit, and assign missions to team members.
- Mission statuses: Planned, In Progress, Completed, Failed.
- Admin can update mission status.
- Team members can update mission status through weekly reports.

## 3. Weekly Progress Reports
- Team members can submit weekly reports for assigned missions.
- Each report includes:
  - Current mission status
  - Progress update
  - Work completed
  - Blockers or problems

## 4. Report Review
- Admin can view submitted reports.
- Admin can mark reports as Reviewed.
- Admin can add comments to reports.

## 5. Dashboard
- Total missions count.
- Active missions count.
- Pending weekly reports count.
- Recent reports.
- Mission status breakdown.
- Progress charts.
